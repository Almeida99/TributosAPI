Como gerenciar suas integrações no TributosAPI

Abaixo estão as funções exclusivas disponíveis para uso nos scripts Python de integração:

Função Descrição
executar_consulta(sql, params) Executa um SELECT no banco e retorna uma lista de registros (dicionários).
executar_insert(sql, params) Executa um INSERT. Realiza commit automático e retorna o número de linhas inseridas.
executar_update(sql, params) Executa um UPDATE. Exige a cláusula WHERE por segurança. Retorna linhas afetadas.
executar_delete(sql, params) Executa um DELETE. Exige a cláusula WHERE por segurança. Retorna linhas deletadas.
http_post(url, data, headers) Envia uma requisição POST para uma API. Retorna {"status": int, "text": str}.
http_get(url, headers) Envia uma requisição GET para uma API. Retorna status e conteúdo textual.
Importante: Comandos como DROP, ALTER e TRUNCATE são bloqueados por segurança.

Esta configuração é utilizada para APIs que exigem uma chamada de login prévia para gerar um token de acesso que será usado na requisição principal.

  • Extração de Token: O sistema utiliza o token_pattern para capturar o valor retornado. Ex: <token>(.*?)</token>.
  • Injeção: Utilize o marcador {token} em qualquer lugar do script para injetar o valor capturado.

O assistente Gemini no canto inferior direito pode:

  • Analisar Erros: Na tela de Logs, clique em "Resumir com IA" para entender falhas técnicas.
  • Ajustar Scripts: Na tela de edição, você pode pedir para a IA reescrever partes do código ou corrigir queries SQL.
