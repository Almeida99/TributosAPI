Documentação Técnica - TributosAPI

Guia completo de funções, segurança e exemplos práticos

1. Operações de Banco de Dados

Funções nativas para manipulação de dados via ODBC.

Exemplo: Consulta e Atualização
# 1. Consultar dados
rows = executar_consulta("SELECT DIV_COD, NOME FROM tb_divida WHERE status = ?", ["ABERTO"])
for r in rows:
    print(f"Processando: {r['NOME']}")

# 2. Atualizar registro após processamento
total = executar_update(
    "UPDATE tb_divida SET status = 'PROCESSADO', data_envio = GETDATE() WHERE DIV_COD = ?",
    [rows[0]['DIV_COD']]
)
logger.info(f"Registros atualizados: {total}")
